# QAIRAQ barbershop — демо-лендинг

Одностраничный сайт барбершопа в Алматы для портфолио. Бизнес вымышленный.

- Чистый HTML + CSS + немного JS, без фреймворков и сборки. Страница весит около 55 КБ (без шрифтов).
- Вёрстка сначала под телефон; на ПК раскладка своя.
- Языки: русский и казахский (переключатель RU/KZ в шапке, выбор запоминается).
  Ссылка сразу на казахском: `.../?lang=kk`.
- Запись через WhatsApp с готовым текстом (в нём название услуги или имя мастера) и через Telegram.
- Индикатор «Сейчас открыто / закрыто» считает время по Алматы.
- Карта Google подгружается только при прокрутке до неё, ключ API не нужен.
- На телефоне внизу закреплены кнопки «Записаться» и «Позвонить».

```
barbershop/
├── index.html        разметка
├── css/style.css     стили
├── js/config.js      ← ВСЁ, что меняется под клиента
├── js/main.js        логика (трогать не нужно)
├── img/              фото и иконка сайта
└── screenshots/      скриншоты для портфолио
```

## Как переделать под нового клиента за 30 минут

Почти всё меняется в одном файле: **`js/config.js`**.

**1. Бренд (2 мин).** `brand.name`, `brand.tagline`, `brand.logoLetter`.
Ещё поправьте `<title>`, `description` и `og:*` в начале `index.html` (их видят Google и мессенджеры при отправке ссылки)
и букву в `img/favicon.svg`.

**2. Цвета (3 мин).** Блок `colors`. Обычно хватает поменять `accent` на фирменный цвет клиента.
Для светлого сайта: `bg: "#f7f4ef"`, `surface: "#ffffff"`, `text: "#1a1a1a"`, `muted: "#6b665f"`.

**3. Контакты (5 мин).**
- `phone` / `phoneRaw` — телефон для показа и для звонка (`+77...`).
- `whatsapp` — номер только цифрами: `77011234567`.
- `telegram`, `instagram` — username без `@`.
- `address`, `district` — на двух языках.
- `mapQuery` — адрес для карты Google, как вы ввели бы его в поиск.
- `twoGisUrl` — откройте карточку клиента в 2ГИС, нажмите «Поделиться» и вставьте ссылку.
- `open` / `close` — часы работы.

**4. Услуги и цены (5 мин).** Массив `services`: название, описание, цена в тенге, длительность в минутах.
`featured: true` выделяет карточку рамкой и плашкой «Выгодно». Карточек может быть сколько угодно.

**5. Фото (10 мин).** Положите фото в `img/` и пропишите пути:
- мастера: `masters[].photo`, например `"img/arman.jpg"`. Лучше вертикальные, примерно 800×840;
- галерея: `gallery[].photo`, квадратные, примерно 800×800;
- фон первого экрана (по желанию): `brand.heroPhoto`, около 1920×1080, тёмное фото подходит лучше всего.

Пока поле пустое, вместо фото показывается аккуратная заглушка.
Перед загрузкой сожмите фото до 150–250 КБ (например, в squoosh.app), тогда сайт будет открываться быстро.

**6. Тексты и отзывы (5 мин).** Тексты интерфейса лежат в `i18n.ru` и `i18n.kk`, отзывы в `reviews`,
рейтинг в `rating`, цифры первого экрана в `stats`. Возьмите реальные отзывы клиента из 2ГИС или Google.

**7. Плашка «демо».** Для реального клиента поставьте `showDemoNote: false`.

Проверьте результат локально (команда ниже) и опубликуйте.

## Запуск локально

```bash
cd barbershop && python3 -m http.server 8080
```

Откройте http://localhost:8080. Если открыть `index.html` двойным кликом, тоже работает.

## Публикация (бесплатно)

**Netlify Drop, самый быстрый способ:** откройте https://app.netlify.com/drop и перетащите папку `barbershop`.
Через минуту будет ссылка вида `https://<имя>.netlify.app`, имя можно поменять в настройках сайта.

**GitHub Pages:**

```bash
cd barbershop
git init && git add . && git commit -m "Barbershop landing"
gh repo create qairaq-barbershop --public --source=. --push
gh api -X POST repos/{owner}/qairaq-barbershop/pages -f "source[branch]=main" -f "source[path]=/"
```

Ссылка: `https://<ваш-логин>.github.io/qairaq-barbershop/`.

Для клиента можно подключить его домен (`.kz` стоит примерно 5–7 тыс. ₸ в год) в настройках Netlify или GitHub Pages.

## Скриншоты

В папке `screenshots/`:
- `mobile-hero.png`, `mobile-hero-kz.png` — первый экран на телефоне (RU и KZ);
- `mobile-full.png` — вся страница на телефоне;
- `desktop-hero.png`, `desktop-full.png` — первый экран и вся страница на ПК.

На скриншотах вместо карты стоит подложка: в headless-браузере Google-карта не успевает прогрузиться. В обычном браузере карта показывается.
